# Klanton Server Preview

Server Preview for Klanton's servers.

### Frontend

The frontend will display current online servers, offline servers, historic servers, settings etc. and aims to make server overview more interactive.

The beginning of the frontend project has React + TypeScript + MUI. The goal over time is to replace React and MUI if possible.

For easier reuse, the frontend will have reusable component building blocks and reusable CSS classes. Configs, variables and functions where possible to avoid manually editing several lines.

The goal of the architecture is to make it expandable. Even though it's a small project for now, we want to make it easier to develop further if we decide to do so.

### Backend

The backend will be developed later on, and is undecided for now.
